ХНУРЕ, спеціальність 126 "Інформаційні системи та технології", група ІСТм-25-1.

| Робота | Тема | Каталог |
|---|---|---|
| ЛР 1-2 | Реалізація криптографічного алгоритму (AES) і геш-функції (SHA-1, Keccak/SHA-3) | [lab1-2](lab1-2) |
| ЛР 3 | Реалізація власного blockchain (UniCoin) | [lab3](lab3) |

Мова реалізації: Python 3.10+. Для запуску тестів: `pip install -r requirements.txt`, далі `python -m pytest` у каталозі роботи.
