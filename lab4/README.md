# Лабораторна робота № 4. Перетворення шістнадцяткових (hex) значень у цілі беззнакові числа

Дисципліна: Інформаційна безпека та децентралізовані технології (ХНУРЕ).

Бібліотека `endian.py` (Python 3, без залежностей) реалізує:

| Функція | Призначення |
|---|---|
| `hex_to_little_endian(hex)` | HEX -> ціле число, перший байт наймолодший |
| `hex_to_big_endian(hex)` | HEX -> ціле число, перший байт найстарший |
| `little_endian_to_hex(n, num_bytes)` | ціле число -> HEX у порядку little-endian |
| `big_endian_to_hex(n, num_bytes)` | ціле число -> HEX у порядку big-endian |
| `describe(hex)` | кількість байтів і обидва подання, як у тестових векторах |

Перетворення виконуються побайтово (зсуви та побітові операції), вбудовані `int.from_bytes` / `int.to_bytes` використовуються лише в тестах як еталон. Довжина чисел не обмежена (довга арифметика Python), тому вектор 4 на 512 байт обробляється без втрати точності.

## Запуск

```bash
python demo.py                 # тестові вектори з методичних вказівок
python endian.py FFFFFFFF      # перетворення довільного значення
pip install pytest && python -m pytest -v
```

## Приклад

```python
from endian import hex_to_little_endian, hex_to_big_endian
hex_to_little_endian("ff" + "00" * 31)   # 255
hex_to_big_endian("ff" + "00" * 31)      # 1153397763...8977280
```
